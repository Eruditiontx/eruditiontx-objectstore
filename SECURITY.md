# Security Policy

## Supported Versions

Security fixes are made on the `DEVELOPMENT` branch and in the latest release of this repository.

## Reporting a Vulnerability

Please report security issues in **this fork** privately through GitHub:
[Report a vulnerability](https://github.com/Eruditiontx/eruditiontx-objectstore/security/advisories/new).
Do not open a public issue.

Please describe the type of issue (for example authentication bypass, information disclosure, DoS), the affected
code path, and the assumptions it needs (for example whether valid credentials are required).

This fork is not maintained by MinIO, Inc., and the upstream open-source project is archived, so please do not send
reports about this repository to MinIO's security contacts.
